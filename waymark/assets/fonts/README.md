# Inter

Unmodified Inter Regular (400), Medium (500), SemiBold (600) and Bold (700),
downloaded 2026-10-18 from the Google Fonts CSS referenced by the Figma export:

`https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap`

TTF source host: `fonts.gstatic.com/s/inter/v20/`. Distributed under SIL OFL 1.1;
see `OFL.txt`. The license was retrieved from the Google Fonts repository through
`https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/inter/OFL.txt` after the GitHub
raw host timed out. Flutter bundles these local files; no runtime font CDN is used.

The Figma reference folder is not a Flutter asset or a runtime dependency.
